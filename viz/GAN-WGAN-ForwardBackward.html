GAN & WGAN — every step of forward and backward

Two networks, two alternating updates. The critical detail: the generator's gradient flows through the second network without updating it. Numbers are real and verified.

step by step — with real numbers
  1. Sample real data   x = 2.0   and noise   z = 0.5
  2. Generate the fake through the frozen generator:   x̂ = w_g·z + b_g = 0.8(0.5) + 0.1 = 0.5
  3. Pre-activation for real:   w_d·x + b_d = 1.0(2.0) + 0 = 2.0
  4. Squash it:   D(x) = σ(2.0) = 0.8808  ← "confidence it's real"
  5. Pre-activation for fake:   w_d·x̂ + b_d = 1.0(0.5) + 0 = 0.5
  6. Squash:   D(x̂) = σ(0.5) = 0.6225
  7. Loss   L_D = −[ log D(x) + log(1 − D(x̂)) ]
    = −[ log(0.8808) + log(0.3775) ] = −[−0.1269 + −0.9741] = 1.1010
  8. Critic score for real:   T(x) = 1.0(2.0) + 0 = 2.0
  9. Critic score for fake:   T(x̂) = 1.0(0.5) + 0 = 0.5
  10. Loss   L_T = T(x̂) − T(x)  (we want T(x) high, T(x̂) low)
    = 0.5 − 2.0 = −1.5000
Notice: the two scores are close (0.88 vs 0.62) — the discriminator is not yet confident. That's healthy early training. If it were 1.00 vs 0.00, Phase H's saturation would be happening.

Why the sigmoid "cancels":  σ'(z) = σ(z)(1−σ(z)), so −1/D · D(1−D) = −(1−D). The logistic derivative and the log derivative annihilate each other — leaving a clean linear expression. The WGAN has no sigmoid and no log, so there's nothing to cancel.

⚠ The extra step WGAN needs: after every update, clip the weights to [−c, c] (here c = 1).
w_d = 1.15 → clipped to 1.00
This is how 1-Lipschitz is enforced — bounding the weights bounds how fast the critic can change. It's why the second network is called a critic, not a discriminator: it outputs an unbounded score, not a probability.

This is the step everyone gets wrong. The gradient passes through the frozen network — it uses ∂D/∂x̂ — but w is never updated on this pass. The discriminator acts as a fixed measuring stick, not a training target.

Look at the magnitudes. The WGAN's gradient is ~2.6× larger here — and crucially it's −w_d, a constant. It does not shrink as the critic gets confident. The GAN's gradient is −(1−D)·w_d, which → 0 as D → 1. That's Phase H's saturation, visible in the formula.

Everything above is one idea: a bounded value saturates; a bounded slope does not. The sigmoid caps D at [0,1], so its derivative dies when it's confident. The Lipschitz constraint caps how fast T may change, but lets its value grow without limit — so the gradient survives even when real and fake are far apart.
