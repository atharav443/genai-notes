Diffusion — Study Sheet

Phases A & B. Theory first, then the questions, my answers, and the corrections.

PHASE A — What a DDPM actually is

1 · The goal hasn't changed

Data: x₀ ~ P_{x₀} (data distribution) Goal: learn to sample from P_{x₀}

Identical to the VAE goal. Everything in diffusion serves this one sentence.

2 · Where we came from

Encoder Decoder x ──▶ z ──▶ x̂ one bottleneck, compressed (k ≪ d)

3 · The leap: a chain of latents (h-VAE)

ENCODING x ▶ z₁ ▶ z₂ ▶ z₃ ▶ … ▶ z_T DECODING z_T ▶ z_{T-1} ▶ … ▶ x A DDPM is an h-VAE. But the latents are NOT more abstract — they are MORE DESTROYED. A hierarchy of damage, not of abstraction.

4 · The three properties that make it a DDPM

(a) Multiple latent spaces
z₁ … z_T
(b) Same size as data
dim(z_t) = dim(x)
(c) Encoder is FIXED
not learnable
Property (c) is the deep one. Your notes (p73):
VAE  : qφ(z|x) : φ is a NN that learned
DDPM: q(z|x)  : is FIXED & not learnable

→ Diffusion removes one of VAE's two unknowns entirely. There is no forward-side posterior to approximate — the forward process is arithmetic you define and control.

5 · The notation trap

VAE: x₁, x₂, …, xₙ subscript = WHICH data point (n examples) DDPM: x₀, x₁, …, x_T subscript = HOW MUCH NOISE (T versions of ONE) x₀ ─noise─▶ x₁ ─noise─▶ x₂ ─▶ … ─▶ x_T image slightly more pure corrupted corrupted static

Same symbol, different meaning. T is a hyperparameter (~1000 in practice).

6 · What is learned vs what is fixed

 VAEDiffusion (DDPM)
latentsone, zT of them, x₁…x_T
latent dimensionk ≪ d (compressed)k = d (same size)
encoderlearned qφ(z|x)FIXED
q is...unknown → approximatedknown exactly
decoderlearned Pθ(x|z)learned Pθ(x_{t-1}|x_t)
ELBO2 terms3 terms
sampling1 pass from N(0,I)T sequential passes
LEARNED : the REVERSE chain x_T → x_{T-1} → … → x₀ FIXED : the FORWARD chain x₀ → x₁ → … → x_T Train by destroying. Generate by un-destroying.

7 · Why the bottleneck moved from size to noise

VAE bottleneck = TOO FEW NUMBERS (k ≪ d — information cannot fit) DDPM bottleneck = TOO MUCH NOISE (information is destroyed) t = 0 ā_t = 1.0 → the image, exact 100% signal t = T/2 ā_t ~ 0.5 → half signal, half static t = T ā_t ~ 0 → x_T ≈ ε 0% signal

At t=T, x_T carries no information about x₀ — it is statistically independent of it. So the model cannot copy; it must invent what was destroyed, and it can only invent from what it has learned about the data distribution. That is the learning pressure VAE got from a narrow z.

One-line summary. A DDPM is a hierarchical VAE with T latents the same size as the data, where the encoder is fixed arithmetic instead of a learned network — so the only thing you learn is the reverse (denoising) chain, and the only thing you generate with is that same chain run backwards.

Phase B — Forward: the fixed destruction

Source p74–75. The shortest phase in the topic — nothing is learned here.

B1 · The equation

x_t = √α_t · x_{t-1} + √(1 − α_t) · ε_t , ε_t ~ N(0, I) ─── signal ─── ────── new noise ────── x₁ = √α₁ x₀ + √(1−α₁) ε₁ x₂ = √α₂ x₁ + √(1−α₂) ε₂ ⋮ x_T = √α_T x_{T-1} + √(1−α_T) ε_T

And the key constraint (p74): α₁ … α_T are fixed scalars in [0,1]. Chosen by us. Not learned. Not optimised.

B2 · What actually happens

x₀ x₁ x₂ … x_T ┌────┐ ┌──────┐ ┌────────┐ ┌────────┐ │image│ → │+ noise│ → │+ more │ → │ pure │ └────┘ └──────┘ │+ noise│ │ static │ └────────┘ └────────┘ 100% signal α₁ signal α₂α₁ signal ~0% "clean" → "noisy" → "noisier" → … → "noise only"

Each step mixes in a fresh noise draw. ε₁ ≠ ε₂ ≠ ε₃ — never reused.

B3 · The Markov property

x_t ⊥⊥ x_{t-2} … x₀ | x_{t-1}

Read as: once you know x_{t-1}, everything earlier is irrelevant. No memory beyond one step. This is what later lets you factorise q(x_{1:T}|x₀) = ∏ q(x_t|x_{t-1}) — a product instead of an intractable joint.

B4 · So each step is a simple Gaussian

q(x_t | x_{t-1}) = N( x_t ; √α_t · x_{t-1} , (1 − α_t) I ) ───────┬─────── ─────┬───── mean variance

You can write this down in closed form. That is the entire point — no network, no ELBO, no approximation. Just q.

B5 · Why exactly √α and √(1−α)?

They are chosen so that variance is preserved:

Var(x_t) = Var( √α_t x_{t-1} + √(1−α_t) ε_t ) = α_t · Var(x_{t-1}) + (1−α_t) · 1 (independent parts add; Var(ε)=1) if Var(x_{t-1}) = 1 : = α_t + (1 − α_t) = 1 ✓

So every x_t has unit variance, including x_T. That is precisely why your notes can claim:

q(x_T) ~ N(0, I) — the stationary distribution of the Markov chain.

The schedule is engineered so that N(0,I) is the fixed point of the destruction process. Two consequences: (1) the final latent distribution is known exactly, so sampling starts from N(0,I) with no guesswork; (2) information decays smoothly from 100% to ~0%, giving T graded difficulty levels.

B6 · What is NOT in this phase

No loss. No ELBO. No gradients. No network. If this phase felt anticlimactic — good, it should. The forward process is the setup, deliberately trivial so that training has a target with a known, exact answer.

B7 · Preview: the closed-form shortcut

q(x_t | x₀) = N( √ā_t · x₀ , (1 − ā_t) I ) where ā_t = ∏_{i=1..t} α_i

Your notes derive this on p85–86 (Phase E). It is what makes training practical: pick a random t and construct x_t immediately, with no loop.

If α_t were learnable, gradient descent would push α_t → 1:

Learning α would let the model choose “add no noise” — making training trivially easy (the identity function) and completely useless. The noise is what CREATES the learning signal. If you let the model tune the noise away, it will.

Three more reasons (for completeness):

① The ELBO assumes q is fixed. A learned q returns you to full variational inference — losing the entire Phase A advantage.

② Training needs x_t in closed form. You construct x_t yourself to get a free supervised target. If α moved, the target drifts every step.

③ It is a design decision, not a data parameter. α encodes “how fast do I want to destroy the signal” — tuned for sample quality. It is not a property of the data distribution.

Phase C — Reverse: the model itself

Source p76. Short phase — but this is the first one where we meet the model rather than the setup.

C1 · The model is a factorisation

Pθ(x₀, x₁, …, x_T) = P(x_T) · ∏_{t=1}^{T} Pθ(x_{t-1} | x_t) ──┬── ─────┬───── starting each reverse distribution step start → x_T → x_{T-1} → … → x₁ → x₀ (noise) (image)

This joint IS “the diffusion model.” When someone says “a diffusion model”, this product is what they mean.

C2 · One step, in detail

Pθ(x_{t-1} | x_t) = N( x_{t-1} ; μθ(x_t) , Σθ(x_t) ) ──┬── ──┬── learned learned

Your notes (p76): “μθ(x_t) & Σθ(x_t) are learned via ELBO.”

C3 · ⚠ The direction trap

FORWARD (q, FIXED): q(x_t | x_{t-1}) cleaner → noisier ↑ ↑ output input REVERSE (Pθ, LEARNED): Pθ(x_{t-1} | x_t) noisier → cleaner ↑ ↑ output input
at t = 500question asked
forward q“given x₄₉₉, what does x₅₀₀ look like?”
reverse Pθ“given x₅₀₀, what was x₄₉₉?”
Same two letters. Opposite arrow. The vertical bar flipped sides — the input/output roles swapped.

If you ever feel lost in diffusion, check which way the bar points. Half the confusion evaporates.

C4 · What is fixed vs what is learned

P(x_T) = N(0, I) ← FIXED. Not learned. Note: NO θ. Known because the forward chain ends there. Pθ(x_{t-1}|x_t) = N(μθ, Σθ) ← LEARNED. This is ALL of the training. model = T learned transitions + 1 fixed starting distribution
The starting distribution costs nothing because Phase B engineered it: the variance-preserving schedule makes N(0,I) the stationary distribution of the forward chain. The forward process manufactured your starting distribution for free — which is why diffusion can sample from nothing.

Notational note: the notes write Pθ(x_T) in the factorisation but then P(x_T) = N(0,I) with no θ. The intent is that it is fixed, not learned.

C5 · The VAE parallel

VAE: Pθ(x, z) = Pθ(x | z) · P(z) decoder prior DDPM: Pθ(x₀, x₁…x_T) = Pθ(x₀|x₁) · Pθ(x₁|x₂) · … · P(x_T) ↑ T decoders, chained

VAE has one decode step z → x. DDPM has T decode steps. That is the entire structural difference.

C6 · Why is the reverse Markov? (be careful)

Your notes say (p76): “arises because of the Markovian (1st order) assumption in the reverse direction…” — note the word assumption.

FORWARD: x_t depends ONLY on x_{t-1} ✓ genuinely Markov (by construction) REVERSE: x_{t-1} depends on x_t AND x₀ q(x_{t-1}|x_t) = ∫ q(x_{t-1}|x_t,x₀) · q(x₀|x_t) dx₀ ── tractable ── ── the problem ──

Many different x₀ can produce similar x_t, so knowing x_t does not tell you which one it was. Reversing a Markov chain does not give a Markov chain.

Analogy: heat spreading through metal is perfectly Markov going forward. But you cannot reverse it from one frame — “the metal is warm in the middle” doesn’t tell you whether it started warm on the left or the right.

Consequence: Pθ(x_{t-1}|x_t) is an approximation, not the true reverse. Its cost appears in Phase D’s consistency term, which compares our Markov model against the honest q(x_{t-1}|x_t,x₀).

C7 · One network, T uses

✗ T separate networks, one per timestep → T × parameters. Absurd. ✓ ONE network, reused at every step, with t as an INPUT model = εθ(x_t, t) or μθ(x_t, t) ↑ the second argument is essential

Why t must be an input: the same weights must behave completely differently at

t = 900 → almost pure noise, must invent most of the image t = 5 → barely noisy, only a small nudge needed

One network cannot do both unless it knows which timestep it is in. That is why Phase F needs positional embeddings of t (p91).

Phase C in one line. The model is the product P(x_T)∏Pθ(x_{t-1}|x_t) — a fixed N(0,I) start times T learned Gaussian reverse steps, each conditioning on the noisier variable and producing the cleaner one, all sharing one t-conditioned network.
